# Milestone SE38 — Open-issue cleanup

## Outcome
Full cycle (implement→code-quality→review→release) fixed + closed the 6 genuinely-open tracker
issues, each TDD-first with real evidence, each closed on GitHub with the fix reference:

- **#117** (`e468bc19`) — REAL security gap: `redactSecrets` leaked a secret value containing `...`
  (the "already-masked" guard was too broad). Now skips only the exact `maskToken` shape. Property
  test made deterministic (pinned seed + `stringMatching`).
- **#116** (`57f7532d`) — `theokit init` templates pinned `zod@^3.25` but the SDK imports the
  top-level `toJSONSchema` (zod v4). Bumped all 3 templates to `^4`; regression derives the required
  major from the SDK peer.
- **#74** (`2ad1a206`, `b37b8c9b`) — docs↔code drift: `docs.md` claimed reload throws on a malformed
  skill, but the deliberate (EC-5) behavior is graceful-skip. Corrected the docs; code+test already
  correct.
- **#48** (`6b7170e8`, `d1d4c865`) — reasoning completion signal had no emitter. Wired
  `thinking-completed` + `thinking_duration_ms` per reasoning block (throw-safe via `finally`).
  Validated end-to-end on deepseek-r1 (OpenRouter).
- **#119** (`65ac5600`) — cross-session state leak: threaded `ctx.threadId` (from the `getOrCreate`
  session key) into the `CustomTool` handler + made `createTodolistTool()` session-scoped.
- **#70** — resolved in the `theokit` repo (`@theokit/agents`, commit `8842bc6f`, 28/28 tests);
  `@theokit/sdk` already emitted `PartialToolCallUpdate`. Closed as done-in-code.
