## Notes / incident log
- During the first release attempt, `pnpm changeset version` ran while the `dev-friendly-custom-provider` feature was uncommitted in the working tree, consuming both changesets prematurely and deleting the (untracked) provider changeset. Recovered via surgical `git restore` of changeset-version outputs (version reverted to 2.0.1) + recreating the provider changeset from the CHANGELOG. No commit/push happened during the mess. The feature was later committed independently (commits 7d53632..ea332da), after which this clean release combined both. Lesson: re-verify `git status` immediately before `changeset version` in a repo with parallel activity.
