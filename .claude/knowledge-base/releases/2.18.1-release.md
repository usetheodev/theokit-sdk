## Release notes

### Patch Changes

- **M7 — cloud pre-release labeling in `docs.md`.** Canonical API contract now carries an
  explicit cloud pre-release banner (Overview) + inline "cloud-only, pre-release" labels on
  `cloud.envVars`, `cloud.autoCreatePR`, `result.git`. Also fixed a teardown race in the cloud
  runtime contract test (dispose flushes fire-and-forget session appends before the temp
  workspace is removed). Docs-only; no API/behavior change; no GA claim.
- **M8 — open-stack front door in README.** "Where this fits" now explains the 4-pillar
  OPEN-STACK composition (UI · Harness · Skills · Runtime), end-to-end composition, honest
  per-pillar status (Runtime/cloud pre-release), validated cross-pillar wiring. Fixes a stale
  `referencia/` reference. Docs-only.

## Test-infra hardening (dev-only, bundled — not consumer-facing)

- Deterministic telemetry-span polling (`findSpanEventually`) across `span-nesting`,
  `agent-send-parent-span`, `span-nesting-e2e` — killed the fixed-sleep flake that
  intermittently saw only `[agent.create]`. 5/5 green.
- `SDK_TEST_MAX_FORKS` env override for the vitest forks pool (default 4 preserved) — memory
  headroom against native-binding OOM under parallel load. Pre-push gate ran with forks=1
  (serial): 434 test files passed, 0 failed, 20 skipped.
