# D401 — Mattermost auth is PAT only in v0.1 (OAuth deferred)

- **Status:** Accepted
- **Date:** 2026-05-28
- **Plan:** `gateway-tier-1-expansion-plan`

## Decision

v0.1 accepts only Personal Access Token (PAT) generated by an admin in System Console → Integrations → Bot Accounts. OAuth flow deferred to v0.2.

## Rationale

PAT issues a fixed bot identity. OAuth requires per-user interactive flow — overkill for a single-identity bot.

## Consequences

Bot operates with one identity. Multi-tenant deferred.
