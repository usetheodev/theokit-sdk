# Milestone SE40 — Native Claude-shaped session format + `--continue` (v4.0 breaking)

## Objective (from ROADMAP.md)

Make the theokit-sdk native session persistence BECOME the Claude Code on-disk shape
(`uuid`/`parentUuid` DAG + structured text/thinking/tool_use/tool_result blocks) at a
configurable `baseDir` with the exact `projects/<encoded-cwd>/<sessionId>.jsonl` layout, so the
Claude Code CLI can `--continue` a theokit session. No `ClaudeCode*` symbols in the SDK; no legacy
kept (the pluggable-storage adapter, SE4 session metadata, and SE33 durable objectives are removed).
