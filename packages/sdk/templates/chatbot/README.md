# TheoKit Chatbot

A simple conversational chatbot built with `@theokit/sdk`. Creates an agent with persistent conversation storage, streams responses in real time, and maintains context across turns via `FileSystemConversationStorage`.

## Usage

```bash
# Set your API key (or use "local" for local runtime)
export THEOKIT_API_KEY="your-key"

# Run the chatbot
npx tsx src/index.ts
```
