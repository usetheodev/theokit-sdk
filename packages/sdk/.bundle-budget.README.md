# Bundle budget — why 215000

The Linux sandbox subsystem was promoted into the SDK, and the plan wrote the consequence down —
*"a macOS/Windows consumer carries ~600 lines in the bundle. Accepted."*

The gate is charging that bill. That is its job, and it is why the number was not raised in
silence.

**Rejected alternative (D1), still rejected:** a sibling package `@theokit/sdk-sandbox-linux`,
analogous to `codex-linux-sandbox`. The analogy does not transfer — that crate exists to isolate
`seccompiler`, `clap` and a binary; here the measured dependency cost is **zero** (only
`node:child_process`, `node:fs`, `node:path`). Creating a package to isolate zero dependencies is
ceremony.

**Reversal trigger, unchanged:** if a native binding or an external dependency enters the sandbox
subsystem, D1 is superseded by the sibling package and this budget returns to 201000.
