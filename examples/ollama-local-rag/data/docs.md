# TypeScript Facts (Sample Corpus)

- TypeScript was created by Anders Hejlsberg at Microsoft and first publicly released in October 2012.
- TypeScript compiles to plain JavaScript and runs anywhere JavaScript runs — browsers, Node.js, Deno, Bun.
- TypeScript's structural type system means two types are compatible if they have the same shape, regardless of declared name.
- The `unknown` type was introduced in TypeScript 3.0 as a type-safe alternative to `any` for values whose type is not known.
- Discriminated unions in TypeScript use a literal-typed common property to narrow the variant inside a switch or if/else block.
- TypeScript's `satisfies` operator (added in 4.9) validates that a value conforms to a type without widening the inferred type.
