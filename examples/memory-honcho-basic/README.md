# memory-honcho-basic

End-to-end demo of [`@usetheo/memory-honcho`](../../packages/memory-honcho).

Highlights Honcho's differentiator: `recall` returns ONE synthesized
**reasoning** answer (dialectic), not k raw facts.

## Setup

```bash
cp .env.example .env
# Set HONCHO_API_KEY (and HONCHO_WORKSPACE_ID) + OPENROUTER_API_KEY
pnpm install
```

## Run

```bash
pnpm start
```
