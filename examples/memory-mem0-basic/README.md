# memory-mem0-basic

End-to-end demo of [`@usetheo/memory-mem0`](../../packages/memory-mem0).

Demonstrates Mem0's unique `history(id)` capability — version tracking
as facts evolve.

## Setup

```bash
cp .env.example .env
# Set MEM0_API_KEY + OPENROUTER_API_KEY
pnpm install
```

## Run

```bash
pnpm start
```
