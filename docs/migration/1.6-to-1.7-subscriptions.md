# Migration: 1.6 → 1.7 — Subscriptions (G8)

> **Additive release.** No breaking changes. `streamAssistant` (a peer vendor AI Data Stream v1, ADR D38) untouched. New `@theokit/sdk/subscription` sub-path ships typed WebSocket + W3C SSE subscriptions with opaque resume tokens.

## What's new

### Server side — `defineSubscription`

```ts
// app/subscriptions/chat.ts
import { defineSubscription } from "@theokit/sdk/subscription";
import { z } from "zod";

export default defineSubscription({
  input: z.object({
    room: z.string(),
    lastEventId: z.string().optional(),
  }),
  output: z.object({
    id: z.string(),
    text: z.string(),
    sender: z.string(),
    ts: z.number(),
  }),
  async *handler(input, ctx) {
    // Resume from cursor when client reconnects with input.lastEventId
    let cursor = input.lastEventId ?? "0";
    while (!ctx.signal.aborted) {
      const msgs = await fetchNewMessages(input.room, cursor);
      for (const m of msgs) {
        cursor = m.id;
        // `tracked` advertises the resume token so the client can echo it back
        yield ctx.tracked(m.id, {
          id: m.id,
          text: m.text,
          sender: m.sender,
          ts: m.ts,
        });
      }
      await sleep(1000);
    }
  },
});
```

### Client side — `subscribe`

```ts
import { subscribe } from "@theokit/sdk/subscription";

for await (const msg of subscribe<
  { room: string },
  { id: string; text: string; sender: string; ts: number }
>(
  "chat",
  { room: "lobby" },
  {
    baseUrl: "http://localhost:3000",
    transport: "auto", // 'ws' | 'sse' | 'auto' (default)
    maxReconnectAttempts: 10, // 0 disables reconnect
  },
)) {
  console.log(`[${msg.sender}] ${msg.text}`);
}
```

## Manual server wiring (without theokit)

```ts
import { createServer } from "node:http";
import {
  mountSubscriptions,
  SubscriptionRuntime,
} from "@theokit/sdk/subscription/internal"; // internal — manual wiring path

const runtime = new SubscriptionRuntime();
runtime.register("chat", await import("./app/subscriptions/chat.js").then((m) => m.default));

// Mount handlers on http.Server
const server = createServer((req, res) => {
  if (req.url?.startsWith("/api/subscriptions/")) {
    void handleSseRequest(req, res); // wire via your http framework
  }
});
server.on("upgrade", (req, socket, head) => {
  if (req.url === "/api/ws") {
    void handleWsUpgrade(req, socket, head);
  }
});
```

## Resume token semantics — opaque, server-defined

`ctx.lastEventId` is **opaque to the SDK**. Server handler decides what it means:

- **Monotonic int** (counter): `"42"` → resume after event 42
- **ULID** (sortable timestamp): `"01H9X..."` → resume after that ULID
- **Encrypted cursor** (opaque blob): consumer decrypts + decodes
- **Timestamp**: `"2026-06-04T15:00:00Z"` → resume after that moment

Mint via `ctx.tracked(id, payload)`:

```ts
yield ctx.tracked(String(Date.now()), { kind: "tick" });
```

## Transport selection

| Mode | When to use |
|---|---|
| `'auto'` (default) | Prefer WS, fall back SSE — works everywhere |
| `'ws'` | Strict — bidirectional needed, error if WS unavailable |
| `'sse'` | Strict — browser-native EventSource, no upgrade |

## Composing with LLM streaming

`Agent.streamObject` (ADR D39) and `defineSubscription` are independent surfaces. You can call `Agent.streamObject` inside a subscription handler:

```ts
export default defineSubscription({
  input: z.object({ topic: z.string() }),
  output: z.object({ kind: z.enum(["partial", "complete"]), text: z.string() }),
  async *handler(input, ctx) {
    let counter = 0;
    const iter = Agent.streamObject({
      schema: z.object({ text: z.string() }),
      prompt: `Write a haiku about ${input.topic}`,
      model: { id: "openrouter/openai/gpt-4o-mini" },
      apiKey: process.env.OPENROUTER_API_KEY,
      local: { settingSources: [] },
    });
    for await (const evt of iter) {
      if (evt.type === "partial") {
        yield ctx.tracked(String(++counter), {
          kind: "partial",
          text: JSON.stringify(evt.partial),
        });
      } else if (evt.type === "complete") {
        yield ctx.tracked(String(++counter), {
          kind: "complete",
          text: evt.object.text,
        });
      }
    }
  },
});
```

The a peer vendor AI Data Stream format (`streamAssistant` + `useChat`) is **unchanged** — coexists with W3C SSE subscriptions.

## Security checklist

1. **Authenticate WS upgrade** via the request object passed to your adapter — auth runs BEFORE upgrade. Rejected upgrade returns 401 (no WS established).
2. **Validate input** via Zod schema (done by SDK automatically).
3. **Bind resume tokens to session** (e.g., HMAC of `userId:eventId`) when token leakage would allow replay.
4. **Force-close on session revocation** via `ctx.disconnect(code, reason)`.
5. **Never log payloads** — telemetry seam captures `{subscriptionName, lastEventId, connectionId}` only (per ADR D34 + D73).

## Why sub-path import?

`@theokit/sdk/subscription` is a dedicated entry point (NOT promoted to `Theokit.subscribe` on the main barrel). This isolates the subscription module from the main `index.ts` DTS bundle, which trips on the pre-existing `agent.ts ↔ fork-agent.ts` rollup-dts cycle (same isolation pattern as `@theokit/sdk/path-safety`).

Once that cycle is broken in a separate refactor, `Theokit.subscribe` can be promoted additively without breaking the sub-path import.
